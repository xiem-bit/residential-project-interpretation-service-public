# 隐藏答案业务评测

本目录只发布评测协议、空白任务模板、量表和观察回执。实际 holdout 原始材料、参考答案和评分锚点必须私下保存，不能进入公开仓、提交历史、发行包或参与者可读路径。

评测对象是住宅项目竞争战略发现和 UE 业务落地，不是 PPT、网页或语言润色。参与者只获得固定候选、`START_HERE.md`和盲态原始输入。

## 必要纪律

- 参与者未参与公开包设计；
- 正式答题前记录输入包哈希；
- 首次运行内容指导为零；
- 机器结构通过后冻结输出，再进入真人盲审；
- 盲审者看不到参与者身份、生产过程和参考答案作者偏好；
- 评分未达标时如实退回，不调整量表或补提示后冒充首次通过；
- 载体产物一律不计分。
