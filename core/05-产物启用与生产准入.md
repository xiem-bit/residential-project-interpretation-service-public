# 产物启用与生产准入

## 1. 不固定生产全套

| 产物 | 默认／典型启用 | 主要职责 |
| --- | --- | --- |
| 产物1 | 住宅研究默认启用 | 竞争态势与本案答案 |
| 产物2 | 客群／购买决策需要深化时 | 购买任务、决策链与产品适配 |
| 产物3 | UE 售前提案或技术标 | 第二章战略推导、第三章UE解决方案 |
| 产物4 | 签约后或完整内容交接 | 单一业务树与生产基线 |
| 产物5 | 售前交互预演或签约后交付 | `presales_focus`或`delivery_full`交互蓝图 |

纯转译、导出或排版继承既有语义。未启用的产物必须记录理由，不创建假完成文件。

## 2. 高成本生产准入

正式 PPT、XMind、交互原型或项目化高保真制作前，至少冻结：

- 项目和任务身份；
- 当前不利观念与目标观念；
- 目标客群与购买任务；
- 有形／无形敌人和有效竞争边界；
- 价值锚点；
- 三至四条成立SC、五项检查、六段因果与推导关系审查；
- 项目承接和事实／权益边界；
- 本轮启用产物、图片职责和关键 gap。

少于三条 SC 时，仍可继续事实整理、素材盘点和可逆骨架，但不能冻结项目专属正式语义或启动正式载体。

## 3. 业务状态与载体状态

业务状态反映战略生产；载体状态反映文件制作。建议独立记录：

- 业务：`semantic_core_frozen`、`minimum_three_sc_pass`、`ue_solution_bridge_pass`；
- 载体：`drafted`、`asset_ready`、`visual_qa_passed`、`formal_artifact_complete`；
- 事件：`reviewed`、`adjudicated`、`published`、`adopted`、`business_effect_observed`。

这些状态互不替代。正式文件已生成不等于客户接受，结构检查通过不等于业务判断成立。

## 4. 生产 Owner 与真人例外

生产 Owner 在现行合同边界内完成研究、冻结、投影和 QA。以下情况交真人裁定：多个同样有效且改变战略的方向；推翻用户已明确裁定；关键身份／权益／价格／交付冲突；超授权外部动作。
