# 权威生产路径

从START_HERE进入，按任务读取AGENT_RULES、相关core、模板和现有工具。当前项目材料优先；发行记录、历史复盘和完整样例按问题调用，不是每次启动的整套前置。

产物1交付真实竞争判断，产物2交付真实选择与购买决策，产物3将已认可判断转成营销价值及UE方案。产物1、2可以独立启用、独立交付；已具备的研究直接消费，不要求完整生产1—3。产物4仅作本工程内部制作衔接，沿用生产端体系；产物5能力及范围保持，按当前语义同步受影响内容。

沿用现有合同及结构化输入，按本任务需要保留业务判断、页面用途、制作内容、讲解脚本和装配确认，不把它们变成五份文件、五个阶段或五次审批。语义冻结表示当前制作依据，新资料或用户裁定可以局部更新。研究与制作之间的引用关系见core/06。

完整深化产物2及完整竞争力方案执行3—4条、至少三条机制不同且有依据的竞争力；产物1独立交付没有该数量或UE要求。UE展示方式不替代竞争力成立依据；不足仅限制相关表达或制作，不自动推翻住宅研究。

当前P3入口是JSON装配清单、页面内容、生产计划及同版PPTX/预览/PDF。Grist不属于当前依赖。指定地图与大图版位由默认模板承接；正文按页面职责完成甲方表达，导出后读回实际文案及图片。工具核对装载，模型承担既有语义审读与逐页视觉判断。

`real_project_delivery`从一开始消费全部授权输入；纯转译、导出、排版使用`non_research_task`；公开虚构样例使用`tutorial`。机器通过只证明其检查范围，不等于真人验收、实际系统交付或业务效果。PRODUCTION_PATH_MANIFEST登记可调用的内容和状态，不是强制的线性流程。
