# 产物 4：单树价值框架

## 1. 定位

产物 4 是签约后的住宅 UE 价值框架与故事线总纲，也是售前承诺进入正式生产的内容基线。它使用一套语义母版和一棵业务树，不按甲方、产品、程序或视觉受众拆成多棵互相漂移的树。

## 2. 节点结构

上层节点供甲方确认业务价值；同一节点的深层、备注或附件供产品经理、原型、程序和视觉岗位生产。稳定引用包括：

- `VALUE-ANCHOR`：全项目价值锚点；
- `SC-*`：超级竞争力；
- `COMMON-*`：通用接待；
- `ROUTE-*`：客户分流路径；
- `MODULE-*`：系统模块／生产内容。

## 3. 启用与接口

产物 4 在签约后完整内容交接、产物 3—4—5 联动或用户明确要求价值框架时启用。它继承语义核，不新增项目价值；可深化表达、制作要求和岗位信息。

每个生效 SC 分支至少连接客户获得、项目事实、UE 场景、模块、验收目的和 `presales_focus`／`delivery_full`适用深度。显示文字可优化，稳定 ID 与业务边界不变。

## 4. 验收

- 只有一个业务根；
- 同一节点同时服务甲方理解和内部生产；
- 所有引用能回到语义核；
- SC、客户路线和模块与产物 3／5 一致；
- 被覆盖节点保留原因，不与当前节点并列生效。
