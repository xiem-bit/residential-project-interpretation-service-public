# 产物 1：竞争态势研究

## 1. 定位

住宅竞争力研究默认先形成产物 1。它统一承接市场、板块、产品价格与竞争结构研究，同时为内部生产和甲方沟通形成同一套竞争答案。

甲方可直接阅读的《竞争态势研究》是首要成果；内部底表和来源治理服务该成果，不把检索日志、渠道状态和系统犹豫前置给甲方。

## 2. 必答内容

1. 项目和任务身份是否闭合；
2. 市场与区域发生了什么，哪些变化真正影响本案；
3. 客户把哪些项目或方案放进同一选择集合；
4. 哪些是直接、局部、间接、内部替代或非竞品；
5. 对手为什么会被选择，本案不能靠什么比较取胜；
6. 当前不利观念和目标观念是什么；
7. 有效竞争边界如何定义，为什么真实；
8. 本案可形成哪些竞争机制和 SC 候选；
9. 哪些缺口会改变答案，哪些信息已经足够；
10. 对后续购买决策研究和 UE 方案意味着什么。

## 3. 竞品发现三视角

- 物理空间：距离、通勤、近场影响；
- 认知货架：市场标签、传播语义、跨板块候选；
- 购买任务：客户用什么方案完成同一进展。

最终角色按生命周期、产品形态、面积／宽总价、销售窗口、购买任务替代和专业判断裁定。市场标签只扩展候选，不自动生成直接竞品。

## 4. 最小对称比较

对核心竞品至少采用同一口径比较：生命周期、产品形态、面积与宽总价、购买任务、关键项目事实、客户得到与承担、进入／筛选／否决作用。先说明对手成立的购买理由，再给本案的避战、重设标准和取舍。

## 5. 产出结构

正式产出由两个配对文件组成：

- `product1-competition-study.md`是甲方可直接阅读的《竞争态势研究》，只承载正式业务表达；
- `product1-competition-summary.json`是后台机器摘要，供公共校验器、统一语义核和跨产物引用使用。

机器摘要至少包含：

- 项目 ID 与输入冻结版本；
- 市场／区域判断；
- 竞品候选及角色裁定；
- 客户认知货架和购买任务线索；
- 当前不利／目标观念；
- 有效边界；
- 三条以上 SC 候选；
- 关键缺口、停止线和 `stop_search` 状态；
- 甲方可见核心结论。

正式报告是依据同一研究结论重新编辑的甲方成果，不是删除内部词后的机器摘要。城市与区域判断、有效竞争圈和本案答案应围绕当前项目逐级递进；检索状态、内部编号、缺口字段和系统自检不进入正文。

## 6. 完成门槛

`product1_complete`要求：甲方报告与机器摘要同时完成；项目身份闭合；直接竞品有替代依据；比较口径对称；对手强项被承认；竞争问题、边界和候选机制清晰；关键缺口已回传或有明确影响处置。文件存在或搜索数量达标不等于完成。
