# 产物 3：从竞争策略到 UE 解决方案

## 1. 产物 3 的业务职责

产物 3 是住宅 UE 售前解决方案与销讲展示策略。其正式载体是可编辑 PPTX，但业务生产单位是“冻结战略判断 + 页面职责 + UE证明关系”，不是视觉风格。

## 2. 第二章：竞争理解与价值推导

第二章按以下链路工作：

```text
真实客户选择
→ 候选与替代关系
→ 客户采用的比较标准
→ 同口径竞争比较
→ 分维度竞争结论
→ 优势收敛
→ SC命名
→ 一句价值锚点
→ 展示策略目标
```

每条结论同时引用本案事实、竞品事实和客户选择逻辑。第二章中的客户是“市场中的选择者”；具体家庭任务、产品匹配、抗性、交互分支和销讲脚本进入第三章。

## 3. 第三章：住宅 UE 系统解决方案

第三章消费第二章答案，不重新发明战略。每条当前 SC 至少形成一个解决方案单元，连接：

```text
SC
→ 客户获得
→ 项目兑现
→ 相对竞争
→ 家庭／购买任务
→ UE场景与交互证明
→ 系统模块与采购范围
```

传统图纸、沙盘和单向销讲为什么难以解释复杂空间，以及 UE 如何通过自由视角、分层点亮、路径漫游和家庭角色切换证明项目价值，属于第三章解决方案内容。

## 4. 跨章桥接

第二章和第三章必须共享项目 ID、语义版本、价值锚点、SC ID／名称、比较对象、购买任务和边界内“唯一和最”。第三章不得弱化或改写第二章；无法用项目事实和 UE 证明时，退回上游修正 SC。

## 5. 预排版与载体适配

新的完整产物 3 在语义冻结后先形成整套页面职责、页序、演讲动作、转场、视觉结构和素材职责，再交真人做必要的结构裁定。只有冻结清单可以驱动专业 PPT 引擎。

装配前先读取`examples/gold-product3-public-safe/gold-authority.json`和当前20页授权真实黄金终稿，再使用17种页面语义按项目重组。当前黄金中的三张真实标准地图、非对称竞争力证明、一页轻量AI推荐官和收口是本案例的真人取舍；它们提供默认质量参考，不形成新项目固定页数。三份更早的成功PPT按已登记公开授权提供完整参考，只继承结构和表达方法，不生成当前项目事实。

产物3中的AI推荐官最多一页，只预告推荐分流；完整推荐结果、二维码和手机延续属于产物5。正式可见标题、超级竞争力、价值锚点和核心论点必须通过断言式人工审校与机械定位。真实地图必须保留底图署名，禁止用AI生成画面替代。

公开核心只要求生成 `product3-chapter2-contract.json`、`product3-chapter3-contract.json`和`ue-solution-handoff.json`。外部平台可自由决定具体版式，但不能改变冻结业务语义。

## 6. 业务验收

`ue_solution_bridge_pass`要求每条 SC 都有客户获得、项目承接、相对比较和可执行 UE 证明，且第二／三章引用一致。PPTX 可编辑和视觉好看属于 adapter 状态，不参与本门槛。

## 家庭证据与画面证明

先把购房者理解为同时处理现实家庭责任、资源约束与长期生活目标的人，从本案识别实际成立的责任、矛盾、希望取得的整体生活进展，以及愿意牺牲与不能牺牲，再形成购买任务、替代选择和项目承接。上班挣钱、养育孩子、照顾老人、长期生活只作启发，可缺席、合并或由项目特有责任替代，不构成固定四栏、固定问卷或每案必填类别。面积、户型、学校、通勤、采光、收纳与空间尺度是承接上位家庭任务的产品证据。

第二章只呈现市场选择和竞争比较，具体家庭路径、产品匹配与空间证明进入第三章。

产物3支撑页继续保持现行至少两处画面／案例版位，并逐图逐页说明证明职责。装饰图不计入合格数量，职责不成立时换图，不以证明职责优化减少规定数量。每条竞争力按机制展开总览与支撑，复杂度决定深度，不机械复制黄金页数。
