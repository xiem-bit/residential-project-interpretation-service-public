# 产物 3：从竞争策略到 UE 解决方案

## 1. 产物 3 的业务职责

产物 3 是住宅 UE 售前解决方案与销讲展示策略。其正式载体是可编辑 PPTX，但业务生产单位是“冻结战略判断 + 页面职责 + UE证明关系”，不是视觉风格。

## 2. 第二章：竞争理解与价值推导

第二章按以下链路工作：

```text
真实客户选择
→ 候选与替代关系
→ 客户采用的比较标准
→ 同口径竞争比较
→ 分维度竞争结论
→ 优势收敛
→ 本案生活主张与成立的竞争理由
→ 一句价值锚点
→ 展示策略目标
```

每条结论同时引用本案事实、竞品事实和客户选择逻辑。第二章保留理解竞争理由所需的购买任务、真实替代与边界；具体产品匹配、交互和讲稿在第三章深化。

## 3. 第三章：住宅 UE 系统解决方案

第三章消费第二章答案，不重新发明战略。每条当前 SC 至少形成一个解决方案单元，连接：

```text
SC
→ 客户获得
→ 项目兑现
→ 相对竞争
→ 家庭／购买任务
→ UE场景与交互证明
→ 系统模块与采购范围
```

传统图纸、沙盘和单向销讲为什么难以解释复杂空间，以及 UE 如何通过自由视角、分层点亮、路径漫游和家庭角色切换证明项目价值，属于第三章解决方案内容。

## 4. 跨章桥接

第二章和第三章必须共享项目 ID、语义版本、价值锚点、SC ID／名称、比较对象、购买任务和边界内“唯一和最”。制作方式不改变已成立的研究判断；新证据冲突才局部更新上游。资料缺失只限制相应制作细节，平面、三维、动画、面板和交互共同承接方案。

## 5. 预排版、制作组合与实际交付

沿用现有装配JSON和当前项目页面内容，在原有预排审阅中确认适用的全屏真实地图、两侧卡片与大图版位。调用`tools/product3_ppt_pipeline/README.md`的默认计划、构建和实际输出校验，不使用Grist，也不新增装配系统。已指定的视觉结构不可自行降级，具体页数、取景和文字按当前项目安排。

第三章现有`system_modules`内定义制作项和UE页面，一份制作内容只定义一次；竞争理由以`ue_page_refs`引用页面，页面通过`production_item_refs`引用制作项。竞争力与页面可多对多；不同`family_routes[].scenes`可共用内容，通过聚焦、预写讲稿和停留重点形成实质差异，菜单负责导航。不得复制制作项模拟不同脚本。

生产端“由项目特点反推、客群用于校验”用于页面组织，既有购买选择研究提供比较及需求依据；两者不互相替代。沿用生产端七级主线和项目层八页默认基准，既有范围字段交代哪些制作、深化或不在本轮，不要求每套脚本和每份PPT展开七级。缺失明细只限制相关细节，不自造组件规范。

标题与价值卡片直接交付本案判断；系统范围页交付系统内容及业务用途，操作和提资说明留在后台。排版前完成专业顾问全文编辑；导出后实际回读主副标题、卡片和地图标签并看图，不能只扫描部分作者字段。相邻页允许重复主张，但依据、观察对象和选择意义须递进。

家庭及AI承担需求概览、系统用途和后续体验承接，完整路径按任务范围展开，不因正式述标自动扩页。同时启用P5且由其深化时，通用证明与系统蓝图先完成，家庭及AI快速收尾；未启用P5而需要PPT详解时，仍提供必要内容，不新增固定模式或逐次审批。

第四章仅在明确授权时启用；公司优势及案例保持独立章节，可按实际授权使用第一章或第四章，不能把开发商品牌等同于供应商优势。完整PPT的完成边界按授权章节据实说明。

## 6. 业务验收

`ue_solution_bridge_pass`要求每条 SC 都有客户获得、项目承接、相对比较和可执行 UE 证明，且第二／三章引用一致。PPTX 可编辑和视觉好看属于 adapter 状态，不参与本门槛。

## 家庭证据与画面证明

先把购房者理解为同时处理现实家庭责任、资源约束与长期生活目标的人，从本案识别实际成立的责任、矛盾、希望取得的整体生活进展，以及愿意牺牲与不能牺牲，再形成购买任务、替代选择和项目承接。上班挣钱、养育孩子、照顾老人、长期生活只作启发，可缺席、合并或由项目特有责任替代，不构成固定四栏、固定问卷或每案必填类别。面积、户型、学校、通勤、采光、收纳与空间尺度是承接上位家庭任务的产品证据。

第二章保留购买任务与比较判断，第三章以具体页面、制作组合及预制讲稿承接。

产物3支撑页继续保持现行至少两处画面／案例版位，并逐图逐页说明证明职责。装饰图不计入合格数量，职责不成立时换图，不以证明职责优化减少规定数量。每条竞争力按机制展开总览与支撑，复杂度决定深度，不机械复制黄金页数。

家庭总览必须配人物肖像，数量按已选定或用户指定版式的人物版位确定；沿用装配输入case_slots，按来源、语义和图片要求逐位装载，不得删除已指定版位或改换已认可版式绕过缺图。相邻地图的类型、来源结构或底图相同不构成重复的充分条件，更换文件也不自动代表增量；由现有逐页语义审读核对信息推进。合同中的choice_event接受真实选择事件、可信市场信号及有依据的顾问综合判断，须如实区分类型和引用，不虚构真人经历或成交结局。价值锚点和竞争力例句只供参考，不要求正文机械出现“最”或“不利观念”；“唯一和最”的比较研究继续保留。

人物画面及相邻文案共同服务本页家庭需要与住宅选择，提示词不能主动消除所需居住关联；风格、年龄与背景按用途选择，不强制摄影或完整房间，也不把示意中的未知配置写成本案事实。
