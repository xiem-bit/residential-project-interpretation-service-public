# 外部上游能力合同

本目录只定义住宅生产核心如何向甲方资料、公开信息、机构数据和专家能力提出任务、接收证据与 gap。上游不裁定直接竞品、价值锚点或超级竞争力。

## 请求原则

- 从一个会改变业务判断的缺口出发；
- 锁定对象、时点、空间、比较字段、配额和停止线；
- 说明结果进入哪个产物、SC候选、购买任务或UE证明；
- 只使用当前有权调用的渠道与资料；
- 证据足够时停止，不要求全城全盘或固定样本数。

请求使用 `upstream-task.schema.json`，回传使用 `upstream-response.schema.json`。回传的 `fulfilled`只表示任务履行，下游仍要登记是否接受、接受到什么用途以及是否改变判断。

任何渠道的单次无命中都不能推导“市场没有”或“竞品没有”；受阻时返回真实的 `gap`、`partial`或`stopped`。
