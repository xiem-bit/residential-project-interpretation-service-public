# 断言式书写规范（Assertion-First Writing Standard）

版本：v1.6
生效日期：2026-09-05
来源：用户提供并裁定用于本工程的成熟写作／编辑规范。

## 0. 元信息与使用方式

- **适用对象**：策略文档、研究报告、售前方案以及HTML、PDF、PPT等客户可见成果中的标题句、论点句、金句、小节句。
- **适用场景**：新写、改写、审校。
- **生效方式**：`AGENTS.md`、任务合同、工单或任务卡引用“书写规范见《断言式书写规范_v1.0》，全文生效”时，本规范全文生效。
- **优先级**：低于内容锁定规则，包括甲方专用名词、事实数据与诚实性语义。本规范管理句式，不改写被锁定内容；两者冲突时，内容锁定优先。
- **一句话总则**：高影响策略句优先断言机制；事实、限制与客户原声保持真实。

### 0.1 执行强度

| 层级 | 对象 | 执行要求 |
| --- | --- | --- |
| A｜强制审校与扫描 | 价值锚点、超级竞争力、策略标题、PPT可见主副标题、核心论点与金句 | 主动检查否定、转折、话题标签和AI式压缩，完成语义覆盖与so-what测试，并运行机械扫描；命中必须人工复核，不要求零命中 |
| B｜正式交付报告式扫描 | 正文判断句、小节句、卡片观点与支撑 | 普通讨论和中间稿不默认扫描；正式交付前以`--report-only`整体扫描一次，只有句式削弱结论、制造歧义或暴露内部方法时改写 |
| C｜内容优先、默认豁免 | 客户原声、竞品及项目原文引文、甲方专名、事实数据、竞品适配边界、风险限制、法律／合同表达、历史记录与小范围事实修订 | 引文允许忠实节选，保留影响判断的条件、转折与上下文，不改写成仿造引语；其他内容保持原意与诚实性，必要否定可以保留；用户提出更严格要求时再升级 |

机械扫描只负责定位。A级强制扫描，B级在正式交付前报告式扫描，C级默认豁免；命中表示“需要人工复核”，不自动表示句子错误，通过也不证明营销语言、事实或策略已经合格。

## 1. 理论源头

### 1.1 肯定形式原则

Strunk & White《The Elements of Style》提出“Put statements in positive form”。否定句要求读者先构建被否定对象，再排除它；肯定句直接描述世界是什么。

### 1.2 论点式标题原则

Barbara Minto《金字塔原理》的action title规范要求：

- 标题是完整论点句；
- 全文标题连读能够独立还原报告主线；
- 每个标题通过so-what测试，读完能够回答“所以呢”。

### 1.3 机制断言原则

转折句输出情绪张力，机制句输出行动指引。策略文档的读者要按文档行动，因此文档必须断言机制。转折句容易模糊信息重心，前半句也会削弱后半句的断言力度。

## 2. 核心规则

### R1 肯定式优先：否定语义正向化

- **触发**：句中出现“不是／不能／不会／并非／没有／难以／无法”。
- **动作**：先判断是否影响理解；需要改写时，把否定对象解释为有依据的业务判断。必要否定、限制与真实对比保持，不以删除否定词为合格条件。
- **示例**：“最终选择不是单一卖点”改为“每一项居住条件都握有否决权”。
- **校验**：改写后原判断、条件和强度不变；不要求否定词消失，不因句式偏好补造机制。

### R2 转折改分层

- **触发**：句中出现“但／但是／然而／却／虽然……但……”。
- **动作**：识别对比双方的真实关系。多数转折表达的是层次差异，例如入场与胜出、条件与结果、基础与裁定。按真实关系决定保留对比或改用分层表达，不机械删除转折、否定或适用条件。
- **示例**：“高新南能进入候选，但不能自动赢得选择”改为“高新南凭区域认知进入候选，靠三向效率、双TOD与家庭一天的具体占位和产品机制赢得选择”。

### R3 条件语义用陈述式表达

- **触发**：原句表达“有条件地成立”，常见形式是“是条件型X，不是Y”。
- **动作**：用“才／以……为条件／只对……成立／当……时”等条件词断言成立条件。
- **示例**：“生活连续是条件型优势，不是中和光环”改为“生活连续与客户日常相连，成熟生活才成为优势”。

### R4 标题是完整论点

- **触发**：一切标题、小节句和金句。
- **动作**：删除“竞争力分析／关于XX”等话题标签式标题；标题包含主语、断言及机制或条件；执行so-what测试。
- **校验**：全文标题连读能够独立读出报告主线。

### R5 语义覆盖校验

- **触发**：每次改写完成后。
- **动作**：回读正文，列出信息点，核对标题或“主推句＋备选句”是否完整收纳。主推句容纳不下的信息进入备选句，禁止丢失语义。
- **审校输出**：高影响句存在争议、用户要求对照或需要顾问裁定时，形成“主推句＋备选＋一句改造理由”。普通批量审校可以直接采用最优句，但必须留下可回读的语义覆盖结果。正式文档只保留最终采用句。

### R6 客户正文只呈现业务世界

- **触发**：甲方版、客户版、外部报告、正式HTML/PDF/PPT。
- **动作**：删除搜索过程、证据等级、候选状态、工程门禁、工具失败、内部裁定和生产方法；改写为市场事实、产品关系、客户选择、项目价值和业务建议。
- **来源表达**：来源身份在后台管理，正文不加“营销转载”“公开推介”“公开价值表达”等前缀，不讲“分期核对”“成组消费”等处理过程。日期、价格、面积、分期、交付条件等实质业务边界保留；缺少具体比较支撑的通用提醒删除。
- **校验**：正文能够被甲方直接阅读，不要求读者理解工程分工、数据治理或人机协作过程。

### R7 内部任务转译为业务判断

- **触发**：“甲方现在要做”“建议甲方补充”“当前不宜前置”“不能据此确认”等内部协作语境。
- **动作**：提取已经成立的市场意义、产品价值、销售表达或条件关系，直接写成客户能够使用的结论。
- **校验**：正式正文不向甲方派研究任务，也不把内部谨慎写成报告主结论。
- **研究报告增量**：“值得逐项比较”“需要看具体总价”“入户体验因此出现差别”等句子只给方法或常识时，继续完成事实间的推导，交付具体竞争压力、取舍或方向。重要分析交付有对象、有依据、有成立边界、对本案有意义的判断；原文、原图、事实与必要背景保留理解和论证职责，不要求每句话都另造断言，也不为追求增量缩写竞品原话。改一个表头不能代替完成判断；没有增量的表格行可以删除。
- **读者语言**：我们书写的正文使用“竞品盘点”“竞品”，不用“逐盘”“各盘”等内部简称；“差别对居住意味着什么”等抽象表头，按具体内容改成“对本案的影响”等日常表达。竞品原文仍按C级锁定。
- **阶段性判断**：信息不完整仍须从当前已知事实形成阶段性竞争判断，允许判断本案面临的压力与可争取方向，不能虚构本案实际产品表现、优势或劣势；具体边界执行`core/02-产物1竞争态势研究.md`。成立条件用比较对象、户型、客户诉求或销售窗口等实际业务条件说明，不写成来源身份前缀或核验说明。不为等待完整甲方信息退回方法论，也不以首稿完全正确为门槛；后续甲方资料、操盘手判断或市场信息用于修订受影响观点。

### R8 结论与支撑就近组合

- **触发**：一切由数据、机构观察或客户选择事件推导的结论。
- **动作**：在结论附近放置具体数据、产品事实、竞品原文、相关画面或合格客户原声。原文出处可用轻量链接追溯；来源身份、完整链接、口径差异与核验记录默认留在内部底稿，任务另有要求时再提供适当附录。
- **校验**：读者可直接理解事实怎样支撑比较，无需阅读核验过程；竞品原文与我们的分析分别呈现，不补造或改写引语。

### R9 官方积极价值转化为客户意义

- **触发**：任务合同或用户裁定允许项目官方价值表达作为客户版事实。
- **动作**：直接表达价值并说明购房者获得，使用专业语言强化项目优势。
- **边界**：价格、学区、产权、保值、交付和权益承诺继续按任务口径表达，营销强化不改变具体承诺。

### R10 正式载体逐页检查

- **触发**：HTML、PDF、PPT正式交付。
- **动作**：除机械文字扫描外，逐页检查标题、引语框、数据表、来源、分页、裁切、重叠和乱码。
- **校验**：文字、数据与版式共同通过；扫描零命中不能替代视觉审阅。

### R11 客户可见 PPT 的前台词与文字版式

- **触发**：甲方正式 PPT 的新写、改版与终版审阅。
- **动作**：把“场景总览、证明／证明模块、客户获得、项目兑现、相对竞争、模块、路径、制作范围、第一步／第二步、形成判断”等页面家族、证明角色或制作步骤留在备注、追溯表和消费包。可见标签、卡片题头和图片题头改写为客户正在判断的关系、项目提供的内容或已经形成的选择结果。系统范围页可以说明实际方案内容和业务用途，此处限制的是后台字段充当前台标签，不是禁用“系统、展示、讲解”等词。第二章的“竞争地图——{维度}”是已定义的导航例外，仍须由可见竞争结论承担断言。
- **文字版式**：原本按一行设计的标题、横幅和短标签不得因文字框过窄而意外换行；可调整我们自己的文案、扩大文字框或调整构图，不用缩小字体掩盖。竞品原文按所选原句保留，需要时扩大版位或增加页面，不为版式提炼、缩写。对称构图、章节扉页和短卡片须人工审定对齐、留白与视觉重心，不以软件默认占位为准。页码、横线等底部元素只有承担明确导航或模板信息职责时保留；没有阅读价值的装饰性页脚应删除。
- **校验**：甲方只需理解项目、客户、画面与方案，不需要理解生产路径；逐页阅读时不出现无意义的换行、失衡文字框或无信息价值的底部噪音。

## 3. 错误模式纠正表

| 错误模式 | 诊断 | 纠正句式 | 纠正示例 |
| --- | --- | --- | --- |
| A，但B | 重心模糊，断言自我削弱 | 凭A进入X，靠B赢得Y；A先定基础，B再完成裁定 | 能进入候选，但不能自动赢得选择 → 凭区域认知进入候选，靠具体占位赢得选择 |
| 是X，不是Y | 两次认知加工，落点在空缺上 | ……才成为……；只对……成立 | 是条件型优势，不是光环 → 与客户日常相连，才成为优势 |
| “XX分析” | 无论点，无法通过so-what测试 | 主语＋断言＋机制 | 竞争力分析 → XX凭三条超级竞争力赢得改善客群 |
| A，但B不能C | 全句停在空缺上，没有行动出口 | B促成X，C完成Y | 价格能促成谈判，却不能替代居住答案 → 价格促成进入谈判，居住答案完成最终决定 |
| 极具竞争力的XX | 无机制、无证据、不可验证 | 凭机制成为结果 | 极具竞争力的产品 → 凭约6米客厅面宽与四房三卫成为同面积段居住答案 |
| 难道不…… | 把断言责任交给读者 | 直接断言 | 难道不是最好的选择吗 → 本案凭X与Y成为该总价段的优先选择 |
| 并非不可能 | 多次认知加工 | 可行，条件是…… | 并非不可能实现 → 可实现，条件是…… |
| A好、B好、C好 | 无裁定逻辑 | A／B／C按顺序或条件共同裁定 | 户型好、公区好、价格好 → 户型楼层朝向先定居住基础，公区车位总价再完成裁定 |

## 4. AI执行流程

1. **分级与扫描**：先判断A／B／C级；A级标出全部否定词和转折词，B级在正式交付前形成`--report-only`报告，C级保持内容优先。
2. **提取**：列出原句及其支撑段落的全部语义点。
3. **判型**：判断语义属于层次差异、条件成立、多因裁定、分工或单纯否定。
4. **组织表达**：按真实判断组织完整语言；句式模板只供参考，不强制套用。
5. **生成**：高影响或争议句形成主推句、备选和改造理由；普通句直接形成最优改写。
6. **校验**：执行语义覆盖校验与so-what测试。
7. **交付**：正式文档只保留采用句；审校记录说明原否定语义由哪个正向断言承接。

## 5. 句式模板库

| 模板 | 结构 | 示例 |
| --- | --- | --- |
| 分层 | 凭A进入X，靠B赢得Y | 凭区域认知进入候选，靠具体占位和产品机制赢得选择 |
| 过程 | A先定基础，B再完成裁定 | 户型楼层朝向先定居住基础，公区车位总价再完成裁定 |
| 条件 | A与B相连，C才成为D | 生活连续与客户日常相连，成熟生活才成为优势 |
| 限定 | C只对具备B的对象成立 | 成熟生活只对生活闭环已在中和的客户成立优势 |
| 裁定 | X由A／B／C共同裁定，每一项都握有否决权 | 最终选择由组合满足共同裁定，每一项居住条件都握有否决权 |
| 分工 | A促成X，B完成Y | 价格促成进入谈判，居住答案完成最终决定 |

## 6. 例外与边界

1. **锁定内容保持原样**：客户原声、竞品及项目原文引文、甲方专用名词、事实数据不受本规范改写。原文即使位于标题或图旁，也按C级锁定；我们另写的分析和标题仍按相应级别审校。允许忠实节选，保留足以理解原意的必要条件、关键转折和上下文；不为压缩篇幅删掉影响判断的信息，也不要求整段、整篇收录。所引文字保持原有措辞，分析与转述另写，不以改写句冒充原话。
2. **封面与结尾金句**：可以用并列结构保留对比张力，例如“白天高效，回家松弛”，仍不使用转折词。
3. **竞争适配边界**：说明竞品、项目或产品不适合什么对象时可以使用必要否定，措辞保持事实性与非攻击性。
4. **风险、合同与能力限制**：真实性高于句式整洁，不得为了通过门禁删除“不外发、不能承诺、尚未完成”等必要边界。
5. **文学化场景**：品牌故事与情感文案由任务发起方声明是否豁免。
6. **产品3更严格语境**：项目任务合同可以对甲方可见PPT设置更严格的禁用句式；该严格口径只约束对应载体，不自动外推到全部内部文档。

## 7. 交付前自检

- [ ] A级高影响句中的转折词已经逐句复核，能够正向表达的已完成改写。
- [ ] A级高影响句中的裸否定已经由正向机制承接；必要限制保留真实语义。
- [ ] 标题通过so-what测试，不使用话题标签。
- [ ] 语义覆盖校验通过，正文信息点进入主推句或备选句。
- [ ] 争议或待裁定句形成主推句、备选和改造理由；普通句完成语义覆盖回读。
- [ ] B级正文正式交付前已完成`--report-only`整体扫描；C级内容没有为了句式整洁损失事实、原声或必要限制。
- [ ] 客户可见正文已经删除搜索、证据等级、内部状态与工程方法。
- [ ] 数据结论附近已经放置机构摘要、来源短注或合格客户原声。
- [ ] HTML、PDF、PPT已经完成逐页视觉检查。
- [ ] 正式 PPT 的页签、卡片题头、图片题头已经完成前台词清理，页面家族与生产方法没有露出。
- [ ] 原定一行的标题和短标签没有意外换行；文字框对齐、留白、页脚和横线均已按当前版面重新审定。

## 8. 产物1—3甲方编辑与交付

产物1、2均为可独立交付的专业报告。首次正式提交前，以“资深咨询公司向甲方营销总提交专业研究报告”的身份完成全文编辑；这是适合甲方阅读的顾问表达，不冒充甲方自述，也不改成楼盘广告。正式排版导出前审理主副标题、正文、表格、卡片、图注和页底说明等全部甲方可见文字；前期可用页面草图组织研究。把方法提示写成已有业务判断，把抽象指代展开为具体行业含义；有依据的“本案应优先争取……”保留为策略建议。改写保持喜欢与购买、超预算与无购买能力、规划与已兑现、未取得与未发布、推演需求与实际客源的区别。断言不夸大确定性；必要条件和不确定性保留，扫描定位后按语义复核，不要求零命中。主体获认可后只复核限定修改及其关联内容。

允许忠实节选，保留足以理解原意的必要条件、关键转折和上下文；不为压缩篇幅删掉影响判断的信息，也不要求整段、整篇收录。所引文字保持原有措辞，分析与转述另写，不以改写句冒充原话。

具体方法采用共用技能`chinese-research-report-editor`的`references/assertion-writing-v2.md`第7节。优先按已安装技能目录发现，不能把维护者私人绝对路径作为分享版唯一依赖。共用技能取得和离线随包方式见`workflows/chinese-affirmative-business-editor/SKILL.md`，缺失时明确报告并补齐，不得静默跳过。

产物3沿用上述全文编辑，但按页面职责判断：价值／家庭／案例页的主副标题直接交付本案判断，卡片写从本案语义内核推导的具体价值、选择或必要条件；系统范围／方案用途页可以说明甲方将购买什么内容、怎样服务销售。内部操作、资料装载及待深化安排留在备注。不能只把“切换、制作”换成“吸引、赋能”，也不能把所有方案页改成楼盘宣传。主张可重复，相邻页的事实、观察对象或选择意义应有推进。少量职责正反例见[页面装配资产](../references/product3/assets/产物3页面模板库/README.md#按页面职责取用的正反例)。

现有逐页审阅先核对本页向甲方交付什么，再核对文字与图像。导出检查以实际文件中的全部可见文字为准，包含副标题、程序添加的说明及页底文字；生成器只装载已编辑文案，不从内部备注补正文。PPT原生文字之外，地图底图与案例自带文字仍须看图判断。扫描负责定位，不能以零命中或技术通过代替语义审读。只改措辞、标点或同用途案例不重开语义冻结；展示对象、观看任务、功能或范围改变时，局部同步既有页面论证、制作项及讲稿。沿用现有编辑和导出检查，不新增自审门或固定审查轮次。

语义反馈按问题类别检查当版相关自写正文、图内固定说明与提示词；标点、换行、同用途换图按局部处理。原语义基线已漏检时，页面或图片指纹不变不能继承通过。整句应交付本案事实、购买取舍或甲方需要理解的系统内容，作者研究、制作和讲解过程留后台；忠实引文的保真与是否采用分开判断。

## 事实订正与比较关系复核

事实订正按对象与依赖关系同步，再回读同版相关结论；不能全局替换相同数字或年份而误改另一对象。整稿重组后检查摘要、建议、图注与讲稿是否重新出现旧判断。客户正文保留年份、报价性质与必要限制，修错历史留在内部。可以索取产品计划、报价和关键权益资料，但不能把本应完成的核心分析变成让甲方填空的比较表。

沿支撑材料检查属性是否足以支持所称效果、对手是否真缺少同类能力、合理偏好是否被扩成全体客户或成交原因。修改新增的解释同样复核，不以虚构客源或效果填补撤回结论。保留已成立的比较与顾问推演，不要求所有判断都有本案成交样本，不新增逐句表单或固定审查轮次。
