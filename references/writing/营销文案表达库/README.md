# 营销文案表达库

状态：`mainline_shared_asset / production_reference / v0.1`

## 一、定位

本库是住宅项目竞争力工程的后台表达参考。它帮助生产 Owner 在当前项目业务语义成立后，学习改善住宅文案的节奏、冲突、数字钉、稀缺边界、连续价值链和家庭结果。

本库承担后台表达参考。当前项目的事实、竞争结论、核心生活主张、三至四条超级竞争力和购买理由，继续由现行消费合同依据当前项目事实、产物1、产物2、营销语义核及附表B推导和验收；原产物6的市场与竞争研究职责已经并入产物1。

- 数据文件：[marketing_copy_reference.v0.1.json](datasets/marketing_copy_reference.v0.1.json)
- 外部参考全量版：[hpsj_value_expression_reference.v0.2.json](datasets/hpsj_value_expression_reference.v0.2.json)；[v0.1](datasets/hpsj_value_expression_reference.v0.1.json)保留为3篇样板基线。
- 上游来源：`100个改善项目稀缺性与极致性价值表达_内容裁定版.xlsx`

- 豪品审局001—016共16篇已逐篇核读，保留67条短原句及其表达职责，去重归纳22条模式；外部图片仍为0；

- 每条记录均标明业务语义、竞争机制、表达角色、来源定位、机械风险标记和生产使用边界。

源工作簿不进入本工程的运行前置。数据文件已经保存全部可消费字段，并记录源文件路径、哈希和标签页形状，后续可核对或重建。

豪品审局全量参考同样不把上游目录变成本工程运行前置。数据文件保留批次入口、逐篇卡路径、文件哈希、正文覆盖状态、短原句、表达职责和使用边界。原句用于保持真实语感与价值力度，生产时仍须依据当前项目事实重写；来源项目数字、权益、唯一性和作者判断不得平移。

## 三、四层结构

1. **原始表达层**：保存原始公开表达、归拢表达和来源指针，任何归纳不得覆盖原文。
2. **归纳模式层**：保存十条写作规律，以及城市、区域、土地、项目、产品五类业务语义入口。
3. **可用候选层**：保存100个项目的“核心价值＋四条竞争力”整理结果，只学习表达结构，不直接复制为当前项目答案。
4. **项目采用层**：只登记真实项目最终采用并完成项目内验收的表达；待裁定稿不进入本层。

外部参考采用轻量生命周期：`source_snapshot → parsed_candidate → reviewed_reference → production_reference`。只有完成来源定位、去项目化、风险标记、职责归类和版本登记的内容，才进入生产检索；来源账号的高频写法不自动成为行业规律。

## 四、现行合同内的调用

生产 Owner 在填写附表B中的行业表达、`slogan`、页面主张和各产物客户可见文案时，按以下方式自动调用本库：

1. 先读取当前项目已经成立的业务语义、竞争机制、事实边界和载体职责；
2. 按“业务语义＋竞争机制＋表达角色／载体”检索一小组表达模式；
3. 只学习句式、节奏和价值转换方法，重新写出当前项目文案；
4. 使用当前项目事实复核数字、唯一性、权益、资产与比较范围；
5. 执行断言式审校，并将结果写回附表B、页面脚本或正式载体。

这一步属于生产 Owner 执行现行合同的后台动作，不新增真人裁定阶段。真人继续在原有业务语义裁定、产物3装配裁定和正式成果审阅位置工作。

## 五、自动调用边界

- 允许自动检索本机已经登记为`production_reference`的数据；
- 不因本库缺少写法而自动启动微信、小红书或其他外部检索；
- 仅影响表达质量的缺口按增强项处理，正式生产继续按已成立业务判断推进；
- 缺口会改变项目事实、竞争边界或超级竞争力时，回到附表A发起正式上游任务；
- 带反问、翻转、负面决策、资产承诺、绝对词或具体数字的记录，必须服从数据中的风险标记和当前项目事实边界；
- 其他项目专属名称、口号、数字、权益、身份、价格与结果不得平移。

## 六、与页面和案例图的关系

本工程不单列“UE证明机制样例集”。产物3的业务装配单位始终是：

`页面语义与视觉结构＋当前项目文案＋案例图／项目化画面`

页面语义库决定这一页为什么存在、装什么内容；本库改善同一业务判断的表达；案例图素材库提供适合该页面价值点的展示参考。三者在当前项目装配页组合，后台保留 ID，前台只呈现真人关心的页序、页面名称、页面文案、视觉变体、底图标准和缩略图。

页面语义、文案模式与图证职责之间的全量路由关系保存在[页面语义与文案及图证联动关系](../../product3/assets/产物3页面模板库/datasets/page_semantic_pairing_profiles.v0.2.json)。它是三库装配关系，不是第四库；不保存外部图片，也不向案例图素材库写入任何来源文章画面。

## 七、维护

- 新来源先进入候选，不直接改写现行数据；
- 每次更新保留源路径、哈希、版本、规模和筛选规则；
- 外部来源同时保留必要短原句、人工转述、表达职责和风险标记；只保存抽象结构会损失真实表达力度；
- 真人修订先进入`learning_feedback`，只有稳定、可跨项目复用的表达方法才升格为本库规则；
- 真实项目采用稿必须保留项目、语义版本、载体和裁定状态，不把一次采用自动变成通用答案；
- 数据重建使用`tools/shared_datasets/build_marketing_copy_dataset.mjs`，并运行共享数据集校验。
