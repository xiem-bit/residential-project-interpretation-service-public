# 中文写作与营销表达生产参考

本目录把中文写作能力作为正式生产能力随包提供：

- `16-断言式书写规范_v1.0.md`：住宅策略写作A／B／C三级完整规范；
- `营销文案表达库/`：100个项目、500条表达、10条写作规律，以及16篇外部表达参考形成的22条模式；
- `human-revision-style-samples.json`：从长期真人修订中抽样的10类稳定语境与改法。

执行时先使用`workflows/chinese-research-report-editor/SKILL.md`完成中文可读性、结构和业务语言审校，再使用`workflows/chinese-affirmative-business-editor/SKILL.md`完成住宅断言、so-what、语义覆盖与A／B／C分级。机械扫描负责定位，不代替人工语义审校。

表达库只提供句式、节奏、价值转换和风险模式。项目名、数字、权益、唯一性、价格与结果必须由当前项目事实重新装载和复核。
