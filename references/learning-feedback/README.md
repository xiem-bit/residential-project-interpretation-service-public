# 真人修订学习反馈

本目录保存公开安全、平台中立的真人修订模式。它与`production_reference`分工明确：

- `production_reference`回答“完整成果达到什么水位”；
- `learning_feedback`回答“真人为什么删、改、压缩或重组，以及哪些判断可以迁移”；
- 两者都不能生成当前项目事实、竞品、客群或超级竞争力。

生产者只在相应阶段读取相关反馈，不需要为每个项目全量加载。反馈记录不包含真实项目名、客户材料、账户、发布地址、运行现场或私有对话；`after`字段描述修订后的通用方向，不冒充可整段复制的甲方文案。

页面职责继续作为既有页面语义字段管理。产物3的完整黄金组合拥有默认优先级，但页数、页序和证明页数量仍由当前项目决定。本目录不新增平行页面库、平行Skill、逐页差异审批或隐藏答案训练。
