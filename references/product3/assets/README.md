# 产物3完整生产参考资产

本目录提供两套获授权参考库：

- `产物3页面模板库/`：124个文件，包含三份历史成功原稿、逐页预览、页面语义、视觉结构和机器数据；
- `产物3案例截图素材库/`：229个文件，包含224张有效案例图、语义台账、检查记录和机器清单。

使用顺序是：先冻结当前项目业务语义，再选页面职责与视觉结构，随后按页面证明目的检索案例图。历史PPT和案例图提供结构、画面与UE表达方法，不提供当前项目事实、竞品、客群、价值锚点或业务效果。

完整清单和授权边界见`../../authorized-reference-assets.json`与`../../AUTHORIZED_REFERENCE_ASSETS.md`。PPT生成引擎与Grist不在本目录，终端用户按`INSTALL.md`自行安装。
