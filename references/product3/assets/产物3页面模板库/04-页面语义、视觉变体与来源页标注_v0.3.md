# 产物3页面语义、视觉变体与来源页标注 v0.3

生成日期：2026-08-25

## 结论

四套成功产物3共96页，归入6个一级语义组、17个业务页面语义和19个视觉结构原型。翠湖云顶二期20页用户验收终稿提供完整新稿的默认优先组合，页面语义库继续负责按当前项目调整、增减和重组。业务语义、视觉结构原型和视觉变体分层管理：页面长得相似，不代表承担同一职责；同一业务语义也允许选择不同视觉变体。

真人不需要记ID。后续在非空白预排页面上按中文选择“竞争地图、证明页、家庭路径”等语义，控制台写入后台ID并把该页标记为“待重组”；Codex据此重做页面职责、演讲动作、转场、必装内容和视觉结构候选，同时保留当前项目已经冻结的事实与判断。

## 聚类归并规则

1. 保留“竞争力场景”与“竞争力证明”：前者先建立主张，后者承担证据；即使都采用“上卡下双图”，也不合并业务语义。
2. 保留“优势收敛”“价值锚点”“竞争力总览”：三者可能都用三卡结构，但分别负责从比较收敛判断、命名全篇总答案、导航逐条展开。
3. “全屏UE展示”属于可操作体验证明，允许兼任竞争力场景或证明，但主语义仍是UE展示。
4. QJ-24经逐页复核由“竞争力场景”调整为“全屏UE展示”，原职责保留为次语义。
5. 翠湖云顶二期提供完整装配的默认优先参考，页数、页序和证明页数量不刚性继承。
6. 历史页只提供结构、动作和内容槽位；项目名、数字、竞品、客群、结论、图片与页脚全部重新装载。

## 真人选择后的执行合同

- 手动选择：在控制台的“页面语义”下拉框直接选中文名称。
