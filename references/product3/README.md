# 产物3页面语义与黄金组合参考

本目录沿用工程既有“页面语义”概念。“页面职责”是页面语义中的一个字段，不另建同义库。生产Owner先读取当前黄金权威，再用`page-semantics.json`按本项目增删、调序和重组。

## 权威优先级

新的完整产物3按以下顺序读取：

1. `examples/gold-product3-public-safe/gold-authority.json`与当前20页授权真实黄金终稿；
2. `examples/gold-product3-public-safe/PAGE_RESPONSIBILITIES.md`；
3. 本目录17种通用页面语义；
4. `HISTORICAL_SUCCESS_DISTILLATION.md`登记的三份历史成功稿匿名结构经验；
5. 单页视觉变体。

完整黄金组合的默认优先级高于孤立页面样例。20页、具体页序和证明页数量不刚性继承，但“可重组”不能成为绕过黄金权威选择、恢复已删除页面或把可选语义升格为默认组合的理由。

## 四套成功稿的共同经验

私有主工程曾以三份历史成功稿76页和当前终稿20页完成96页逐页标注，收敛为6个一级语义组、17种页面语义和19个视觉结构原型。其他三份客户PPT未获本轮公开授权，因此只迁移结构经验，不复制项目名、数字、竞品、客群、结论、图片或页脚。

跨稿稳定规则是：先定义真实选择局面，再用竞争地图重设比较标准；超级竞争力先建立客户获得与项目机制，再按证据非对称证明；每页标题用断言回答“所以呢”；AI推荐官在产物3只做一页轻量预告；用户验收终稿和最新实际页码高于旧线稿、页码计划和历史QA。

## 删除与禁用清单

1. 不把内部生产流程、检索任务、schema、validator或QA状态做成甲方页面；
2. 不把研究方法单独扩写成低价值过程页；
3. 不在相邻页面重复解释同一竞争力；
4. 不恢复用户已删除的过渡页和空洞大标题页；
5. 不把产物5的完整AI推荐、二维码、手机延续和交互内容塞进产物3；
6. 不为了整齐让三条竞争力机械使用相同页数；
7. 没有独立购买判断、项目关系或图证，不新增证明页；
8. 不用面积、户型标签或人物照片直接推导家庭阶段；
9. 未获授权的甲方原始截图及其轻度变体不进入正式PPT；已明确公开授权的真实资料按授权边界使用；
10. 不用AI生成画面替代真实标准地图；地图页保留OpenStreetMap或实际底图服务署名；
11. 不为了接近黄金页数恢复已被业务删除的内容；
12. 不把结构检查、渲染成功或目录自洽写成黄金来源选择正确。

## 首稿完整度与断言门槛

首次提交用户审阅的版本必须完成整体结构、正式文案、真实或已授权图片装配、基本视觉排版、逐页渲染和客户可见内容检查。空槽稿、仅有标题的骨架稿、未装图片的结构试错稿和明显低密度草稿不能作为首稿提交。

A级标题、价值锚点、超级竞争力、核心论点和金句必须先完成人工断言式语义审校，再运行机械扫描定位；B级正文在正式交付前使用`--report-only`整体复核；客户原声、专名、事实数据和用户验收终稿不因扫描命中自动改写。

最终以论证完整、甲方表达有效、图片与地图合规、同版QA和真人验收为准。
