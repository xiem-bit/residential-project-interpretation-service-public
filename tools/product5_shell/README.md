# 产物5 `presales_focus` 项目中立黄金实现

本目录是公开发行包中唯一的产物5运行时源码。默认装载的“青岚澄境”及全部城市、竞品、客户、数字和画面均为公开安全的合成示例；真实项目必须替换`public/project-data.js`中的全部项目专属内容。

## 已继承能力

- 全屏场景底图、左右信息层、底部一级导航和悬停二级内容带；
- 城市关系、红线内园林与归家、家庭空间三类默认UE场景；
- 数字递增、按钮反馈、章节转场、推荐生成和结果进入动效，并兼容`prefers-reduced-motion`；
- 四问分流、三类专属建议、独立结果背景和右侧滚动结果；
- 每组建议固定包含直接判断、家庭处境、三项理由、三步体验、两项比较条件和下一步安排；
- 桌面端与真实手机竖版页共享同一条路线数据；
- 只有配置正式HTTPS地址后才显示可扫描二维码，本地阶段不伪造公开网址；
- 图片预加载、非根路径构建、静态包清单和项目残留扫描。

## 使用

```bash
npm ci --ignore-scripts
npm run dev
npm run build
npm test
```

正式项目先完成产物1、产物2、统一语义核和产物5输入冻结，再替换配置和视觉资产。客户可见正文不得出现检索状态、证据缺口、内部ID、验证器或生产任务；这些信息继续保留在配置合同和回执中。

二维码由`VITE_PUBLIC_BASE_URL`控制。只有当值为真实、已复核的HTTPS地址时才生成；发布授权、账户、域名和有效期均不进入本公开参考。
