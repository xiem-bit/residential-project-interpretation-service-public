# 中文业务文档断言式修订

## 适用依据

书写规范见`references/writing/16-断言式书写规范_v1.0.md`。我们新写的价值锚点、超级竞争力、主副标题、核心论点和金句按A级执行；普通正文按B级复核；客户原声、竞品及项目原文引文、事实、限制和专名按C级保持内容优先。允许忠实节选，保留足以理解原意的必要条件、关键转折和上下文；不为压缩篇幅删掉影响判断的信息，也不要求整段、整篇收录。所引文字保持原有措辞，分析与转述另写，不以改写句冒充原话。

本技能与通用中文研究报告修订能力配合使用。通用能力负责读者用途、完整指代、业务关系、语气和语义保真；本技能落实住宅A／B／C审校。必要否定和转折按含义保留，不强制正向化或套用模板。

## 执行范围

- 策略文档、售前方案、PPT课件的标题句、论点句、金句和小节句；
- 住宅工程产物1—3的新写、改写和审校（按references/writing/16第8节区分页面职责）；
- 用户要求执行肯定式、陈述式或断言式写作时。

## 执行流程

1. 读取当前工程`AGENTS.md`、当前已启用产物的core规范、`references/writing/16-断言式书写规范_v1.0.md`及当前任务合同。
2. 扫描主副标题、论点句、金句和小节句中的全部否定词与转折词。
3. 列出原句及支撑段落的信息点，判断语义关系：层次差异、条件成立、多因裁定、分工或单纯否定。
4. 高影响争议句按规范形成主推句、备选与改造理由。普通句直接采用最优改写；客户原声、事实限制和专名不为句式整洁而改写。
5. 对每个标题执行so-what测试，并连读全部标题，确认能够独立还原主线。
6. 回读正文，确认事实、条件、比较关系、客户任务和行动含义没有丢失。
   - 产物1同时检查是否交付了具体观点：“值得比较”“需看总价”“体验不同”等方法或常识句，应继续推导成竞品选择、本案压力或方向；没有增量的内容删除。首次拜访按已有事实提出阶段性判断，后续输入再修订，不等待信息全齐。
   - 客户正文使用“竞品盘点”“竞品”；“逐盘”“各盘”仅可在内部方法说明或锁定引文中出现。比较同名配置时保留使用对象与具体用途的差异。
7. 按执行等级运行机械门禁。A级强制运行：

   ```bash
   python3 tools/chinese_copy_lint/affirmative_statement_lint.py <文件1> <文件2>
   ```

8. A级扫描只针对我们新写或改写的论点。C级原文引文直接锁定，在审校记录标明引用范围并核对原句，不为通过扫描改写。A级中用户裁定保留的特定营销金句，可通过精确短语白名单豁免：

   ```bash
   python3 tools/chinese_copy_lint/affirmative_statement_lint.py \
     --allow-file <当前项目精确例外清单> <文件1> <文件2>
   ```

9. B级正文只在正式交付前使用`--report-only`整体扫描；普通讨论与中间稿不默认运行。C级客户原声、竞品及项目原文引文、事实数据、专名、必要限制、历史记录和小范围事实修订默认不因句式扫描改写，用户提出更严格要求时再升级。
10. 对命中项完成人工复核。A级句完成改写或取得明确裁定；B级句只处理削弱结论、制造歧义或暴露内部方法的命中；C级保持真实。扫描通过不证明事实、营销语言或策略已经合格。

## 禁止事项

- 正则自动批量改写复杂语义；
- 只删除否定词，不补齐世界实际怎样；
- 为追求短句丢失入场与胜出、条件与结果、基础与裁定等层次；
- 把`先……再……`机械判错。它在准确表达过程或分层时属于规范模板；
- 用全句、整段或整类句式白名单掩盖未审校问题。
- 在甲方正文添加“营销转载”“公开推介”等来源身份前缀，或把来源处理、核验方法写成业务内容；完整来源信息留在内部，必要出处用轻量链接追溯。


## 甲方正文编辑与定稿范围

产物1—3首次提交的全文编辑、页面职责、判断保真及实际交付核对，统一执行`references/writing/16`第8节；这里不另存一份会分叉的条款。


通用编辑能力直接读取本包workflows/chinese-research-report-editor，不依赖维护者私人技能目录。
