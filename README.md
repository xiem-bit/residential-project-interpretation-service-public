# 住宅项目竞争力生产核心

本仓库公开的是一条完整的住宅项目业务生产路径：从已授权原始材料出发，识别项目真正的竞争问题、有效竞争圈、客户购买任务和竞争解法，形成三至四条成立的超级竞争力，再把同一业务判断投影到住宅 UE 售前方案和交互原型。

PPTX和网页是可替换的下游载体。它们可以由 Codex、其他 Agent、专业平台或人工团队制作；载体是否美观不构成本工程住宅战略发现能力的通过证据。

公开预发行版 `v0.2.0-rc.2` 已完成P0能力同构冻结，并已补入现行生产约束、增量检索、业务Harness、两套不同机制的完整公开安全项目、真人修订反馈以及产物1、2、3、5的黄金参考。产物3以用户验收的20页授权真实终稿为最高权威，并完整携带三份获授权历史成功原稿、124文件页面模板库、229文件案例素材库、营销文案库、中文报告编辑与断言写作能力；本轮资产扩容后的干净克隆、全包安装和GitHub CI验收已经通过。产物4因即将进行上游大修，不进入本次公开发行范围，也没有可安装入口。`v0.2.0-rc.1`因历史RC1检查脚本的CI调用缺陷由`rc.2`取代，既有标签保持不可移动。请先读取 [发行状态](RELEASE_STATUS.md) 和 [能力同构合同](CAPABILITY_PARITY_CONTRACT.md)。

本公共仓的固定提交与后续固定标签是唯一发行权威。WorkBuddy、Codex 或其他平台工作区
只能克隆并消费公开包；把文件直接复制进某台电脑的某个平台目录，不构成公开发布，也

## 本版新增的核心能力

- 以原始项目材料和轻量任务合同为入口，不再把现成语义核作为默认输入；
- 完整覆盖项目身份、事实／冲突／缺口、产物 1、产物 2、统一语义核、超级竞争力、产物启用与生产准入；
- 连续连接产物 3 第二章竞争推导、第三章 UE 证明与产物 5 交互蓝图；
- 语义变化先回写上游，再只重投影受影响产物；
- 提供平台中立的生产编排 Skill、模板、Schema、机器否决型Harness、公开回归fixture和公开安全黄金参考；
- 完整携带中文报告编辑、断言写作、人工修订语境、页面原稿、模板、案例图和营销表达资产；
- 用六段SC因果和允许／禁止推导关系约束证据跨步，不把禁词扫描或机器得分当成商业判断；
- 把业务生产路径验收与 PPT／网页适配器验收彻底分开。

## 快速验证

Python 核心只使用标准库：

```bash
python3 tests/run_public_tests.py
python3 scripts/verify_production_run.py examples/production-path-tutorial/expected --mode tutorial
```

其他电脑完整试装请读取[Codex安装与自检](INSTALL.md)，并运行现有`check_environment.py` doctor；住宅研究主链、产物3参考与产物5运行时按需检查，不把Node设为所有任务的前置。

旧 RC1 的载体往返演示仍可独立运行：

```bash
python3 scripts/run_rc1_demo.py --install-node-deps
```

它只验证下游合同、PPTX 结构和静态包，不验证住宅竞争战略发现能力。
