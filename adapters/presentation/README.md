# 演示文稿适配器边界

输入只能来自冻结的产物 3 第二／三章合同和 UE 交接。新的完整产物3还应先读取`references/product3/`的页面语义，以及`examples/gold-product3-public-safe/`的当前完整黄金组合，再按本项目重新装载、增删、调序和重组。黄金组合的默认优先级高于孤立页面样例，但19页、具体页序和证明页数量不刚性继承。

适配器可以优化叙事节奏、版式、画面和对象结构，但不得改变业务语义，也不得复制黄金参考中的项目事实、客户、竞品、图像或结论。首次提交审阅的版本必须已经完成正式文案、图片装配、可编辑PPTX、逐页渲染和视觉检查；不新增平行页面职责库、产物3 Skill或逐页差异审批。

可编辑PPTX、页面映射、对象映射、逐页预览和视觉复核属于presentation adapter证据。它们与住宅战略发现、专业语义审查和真人业务接受状态完全分离。
