# 演示文稿适配器边界

输入只能来自冻结的产物 3 第二／三章合同和 UE 交接。新的完整产物3还应先读取`examples/gold-product3-public-safe/gold-authority.json`、当前20页授权真实黄金终稿及其页面职责，再读取`references/product3/`的通用页面语义，最后按本项目重新装载、增删、调序和重组。黄金权威高于结构蒸馏稿和孤立页面样例；20页、具体页序和3／4／2证明深度不刚性继承。

适配器可以优化叙事节奏、版式、画面和对象结构，但不得改变业务语义。黄金参考中的真实项目事实、客户、竞品、图像或结论只在该参考的明确公开授权范围内保留；新项目必须消费自己的已授权输入，不得从黄金参考复制事实。首次提交审阅的版本必须已经完成正式文案、图片装配、可编辑PPTX、逐页渲染、断言审校和视觉检查；不新增平行页面职责库、产物3 Skill或逐页差异审批。

第5—7页的真实标准地图及OpenStreetMap署名属于当前黄金终稿的一部分，不得改用AI生成地图。产物3中的AI推荐官最多一页并保持轻量预告；完整条件识别、推荐结果、二维码和手机延续由产物5承担。

可编辑PPTX、页面映射、对象映射、逐页预览和视觉复核属于presentation adapter证据。它们与黄金来源选择、住宅战略发现、专业语义审查和真人业务接受状态完全分离；结构测试通过不能证明采用了正确黄金权威。
