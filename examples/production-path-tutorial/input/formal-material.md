# 虚构甲方正式材料摘录

## 项目身份与底盘

- 规范名与推广名均为“青岚澄境”；开发主体为“澄川青岚置业有限公司”（均虚构）。
- 位于虚构澄川市青岚新区东岸生活带，本轮只讨论一个整体项目，不含其他分期。
- 12 栋 8—11 层住宅，容积率 1.45，绿地率 38%。
- 产品面积为 128、143、168 平方米。
- 143 与 168 平方米设置双套房关系；143 平方米含可变书房。
- 入口、首层园林、架空层与地下会所按连续归家关系组织，但尚无正式效果图。

## 材料差异与未知

- 简报 A 写用地面积 61,800 平方米，规划摘要 B 写 62,300 平方米。
- 正式测距只登记既有轨道节点约 2.4 公里直线距离；营销口述出现“2.1 公里步行”，没有路线依据。
- 首开价格、付款条件、学校建设与入学权益、正式交付时间均未提供。

## 甲方初始表达

“东岸唯一低密住区”“双轨生活”“名校旁”“全龄度假社区”。这些词只是待研究主张，不是已批准结论。
