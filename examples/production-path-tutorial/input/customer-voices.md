# 合成客户声音与选择事件

以下均为测试用合成句，不是真实受访者或平台数据。

- `VOICE-01`：“我和爱人在两个方向上班，房子可以远一点，但每天的时间不能完全押在一条路上。”
- `VOICE-02`：“北湾府方便是真的，楼下也成熟；青岚这边如果只是环境好，我不会为了低密多走那么远。”
- `VOICE-03`：“父母一年会来住几个月，最好各自有卫生间，平时又别浪费一间房。”
- `VOICE-04`：“栖霞里的会所已经能看见，这边讲园林和地下空间，最好让我一次看懂怎么走、怎么用。”
- `VOICE-05`：“价格还没出来，我不着急定，多看看也没有损失。”
- `VOICE-06`：“学校如果只是规划，就别当成我买房的理由；我更在意每天能不能稳定接送。”

这些材料只提供有限场景，不代表总体客户比例或市场共识。
