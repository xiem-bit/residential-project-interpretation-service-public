# 完整生产路径教程：青岚澄境（全量虚构）

本教程验证从原始材料开始的住宅生产主链。所有城市、企业、项目、竞品、客户声音和数字均为合成数据，不对应真实对象。

## 正确用法

1. 只读取 `input/`，把它复制到一个新的运行目录；
2. 按公开生产 Skill 独立完成十二份必需输出；
3. 运行公共机器校验；
4. 冻结自己的答案后，才读取 `expected/`对照；
5. 不把教程对照写成独立盲审通过。

`expected/`展示完整生产链如何保持事实冲突、竞品强项、购买任务、三条不同机制的 SC、UE 证明和 gap。它是教学参考和回归夹具，不是隐藏答案评测。

旧 `examples/fictional-qinglan-chengjing/work/semantic_core.json`属于 RC1 下游适配演示。新教程不读取它，也不把它作为生产输入。
