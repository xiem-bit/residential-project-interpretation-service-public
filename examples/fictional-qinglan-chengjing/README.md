# 青岚澄境：历史 RC1 下游载体适配演示

本目录属于固定版本 `v0.1.0-rc.1` 的历史演示。它从已经审定的
`work/semantic_core.json` 开始，只验证下游合同、平台往返、PPTX 结构和静态网页包；
不验证系统能否从原始材料发现住宅竞争问题、购买任务或超级竞争力。

需要复刻完整生产路径时，应从 `examples/production-path-tutorial/` 开始，并把统一语义核
作为生产输出，而不是启动输入。

`青岚澄境`、澄川市、青岚新区、开发主体、竞品、客户原声和全部数字均为合成测试
数据，不对应任何真实项目或机构。项目被特意设计为包含真实住宅研究常见摩擦，
而不是一份无冲突的玩具样例。

## 输入中故意保留的问题

- 两份虚构甲方材料对用地面积给出不同数字；
- 轨道距离存在直线距离与未核步行距离的口径差；
- 学校、价格、交付时间和部分交通兑现处于待核实状态；
- 两个虚构竞品分别在成熟通勤和低密社区上更强；
- 客户声音同时包含跨城通勤、三代短住、总价纪律和继续等待；
- 甲方营销主张中混有可用、需加边界和应拒绝三种状态；
- UE 只有语义素材，没有真实图片、地图底图或客户资产。

## 文件职责

- `input/`：模拟陌生用户能够交给 Agent 的原始材料；
- `work/semantic_core.json`：已审定的虚构项目统一语义核，是本示例的生产输入；
- `verification-tmp/fictional-demo/`：运行后生成的合同、PPTX、产物5静态包与回执。

该示例只能验证历史 RC1 的下游载体链路，不得作为完整生产路径或住宅战略发现能力的
通过证据。替换成真实项目时，必须重新建立项目事实、竞品、客户任务和超级竞争力，
不能复用本示例答案。
