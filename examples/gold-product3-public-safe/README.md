# 产物3公开安全黄金参考

本目录提供一套可编辑、可渲染、可检查的产物3完整参考。项目“青岚澄境”、城市、竞品、客户声音、产品参数和全部画面均为虚构或公开安全生成内容，不包含真实甲方文件、客户材料、本机私有项目事实或发布配置。

## 目录内容

- `青岚澄境-住宅UE售前解决方案与销讲展示策略_公开安全黄金参考.pptx`：19页可编辑PPTX；
- 同名`.inspect.ndjson`：演示文稿的机器可读对象与备注检查结果；
- `qa/deck-montage.webp`：19页同版总览；
- `qa/slide-*.png`：封面、价值锚点、家庭分流、AI推荐官和最终收口的代表页；
- `qa/design-qa.md`：视觉、版面、文案和公开安全检查记录。

每页演讲者备注均包含`[Sources]`，来源只指向本公开包内的虚构教程、语义核、产物5资产登记和公开安全界面截图。

## 它教会什么

这套参考展示一条完整生产路径：

1. 用有限客户声音识别选择条件，不把社媒或访谈样本外推成市场比例；
2. 把直接竞品与继续等待放入同一购买局面；
3. 从进入候选、赢得比较和推进行动三张竞争地图收敛价值锚点；
4. 让三条超级竞争力分别闭合项目事实、相对竞争、客户意义、项目承接、UE证明和行动结果；
5. 按家庭现实任务组织看房路线，不用面积或人物照片代替家庭判断；
6. 将已成立业务语义投影为UE制作蓝图，再由产物5网页证明全屏接待、AI推荐和手机延续。

## 正确使用方式

新的完整产物3先读取`references/product3/`中的页面语义，再把本套完整组合当作默认优先参考。继承的是叙事节奏、页面语义、视觉结构、对象版位和表达密度；当前项目的标题、事实、竞品、客群、图像、超级竞争力和结论必须重新装载。

19页不是固定模板。页数、页序和证明页数量服从当前项目的竞争机制与证据条件；没有新增客户判断、项目关系或独立图证时，不新增页面。首次交给用户审阅的版本必须已经完成正式文案、图片装配、可编辑PPTX、逐页渲染和视觉检查。

## 使用边界

- 本套参考不是房地产市场事实数据集，也不能作为任何真实城市或项目的事实来源；
- 页面中的UE界面来自本包产物5公开安全黄金实现，只证明产品能力与交互关系，不代表真实系统已经部署；
- 客户声音是虚构教学样本，只用于示范证据边界和比较机制；
- 真实项目仍应先完成产物1、产物2、统一语义核与超级竞争力冻结，再启动正式PPT生产。
