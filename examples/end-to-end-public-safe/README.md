# 多机制公开安全完整项目

本目录与`examples/production-path-tutorial/`共同构成公开发行包的完整项目参考。

- `production-path-tutorial/`：青岚澄境，全量虚构，演示低密改善、双向就业、家庭弹性，以及产物1、2、3、5同时启用的完整链路；
- `end-to-end-public-safe/fictional-wangchuan-xu/`：望川序，全量虚构，演示城市核心换新、三锚日常、装修决策清晰度和弹性房间，以及只启用产物1时如何完整收口。

两套项目的市场、项目、竞品、客户声音和结论都不能作为真实城市事实。它们的用途是展示不同机制、不同启用矩阵和同一业务门槛。生产者应从当前项目原始材料重新研究，不能复制示例答案。
