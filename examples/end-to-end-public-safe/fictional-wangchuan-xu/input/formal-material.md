# 望川序项目资料（全量虚构）

- 项目位于虚构澜州市中城北岸，为单一宗地、单一推广名和单一开发主体；
- 规划6栋27—31层住宅，产品为112、128、142平方米；
- 112与128平方米均设置一间可在独立书房、儿童活动和临时照护之间切换的弹性房，隔墙、采光、收纳和通行边界已在图纸中标明；
- 交付标准清单已经列明厨房、卫浴、收纳和设备边界，但交付日期与最终价格尚未正式发布；
- 项目组织了一次虚构工作日路线核验：项目至北岸商务区、宁河实验中学和长辈住址三个锚点分别记录了完整道路路径；这次单日核验不能代表长期平均通勤；
- 本案不是现房，资料不构成按期交付、品质结果或资产价值承诺。
